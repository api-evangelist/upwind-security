# Upwind Security

Upwind is a cloud security (CNAPP) platform that pairs cloud security posture with eBPF-based runtime protection across AWS, Azure, Google Cloud, and Oracle Cloud. Its Management REST API (v1 and v2) exposes threats, vulnerabilities, configurations, inventory, SBOM packages, workflows, and access management using OAuth 2.0 client credentials, and the company ships a hosted MCP server (mcp.upwind.io) plus an official Agent Skill for AI coding assistants.

Backed by: bessemer-venture-partners — https://www.upwind.io/

This repository indexes Upwind's public API surface in [apis.yml](apis.yml): OpenAPI 3.1 specs for the Management REST API, MCP server profile, provider-published Agent Skill, OAuth scopes, authentication profile, packages (Terraform/Helm/GitHub Actions), upwindctl CLI, webhooks, conventions, error catalog, lifecycle, conformance, data model, well-known documents, and security posture.
