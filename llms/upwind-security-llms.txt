# Upwind Security

> Upwind is a cloud security (CNAPP) platform that combines cloud posture with eBPF-based runtime protection across AWS, Azure, Google Cloud, and Oracle Cloud. Its Management REST API (v1 and v2) exposes threats, vulnerabilities, configurations, inventory, API security, SBOM packages, workflows, and access management, secured with OAuth 2.0 client credentials. Upwind also ships a hosted MCP server and an official Agent Skill for AI coding assistants.

Generated by API Evangelist from the provider's public surface on 2026-07-21 (Upwind publishes no llms.txt of its own).

## APIs

- [Management REST API v2 (current)](https://docs.upwind.io/restapi/v2/introduction): Base URLs https://api.upwind.io, https://api.eu.upwind.io, https://api.me.upwind.io; paths /v2/organizations/{organization-id}/...
- [Management REST API v1 (maintenance mode)](https://docs.upwind.io/restapi/v2/introduction): paths /v1/organizations/{organization-id}/...

## Specs

- [OpenAPI 3.1 — v1](https://docs.upwind.io/restapi/management/v1/openapi.yaml): 35 operations across threats, vulnerabilities, configurations, cloud-accounts, workflows, integrations, events, api-security, packages, shiftleft
- [OpenAPI 3.1 — v2](https://docs.upwind.io/restapi/management/v2/openapi.yaml): 48 operations across inventory, threats, events, configurations, api-security, access-management
